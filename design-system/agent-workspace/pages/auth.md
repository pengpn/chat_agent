# Auth 页面规范

本文件覆盖登录、注册、忘记密码、邮箱验证和重置密码流程；其余规则继承全局设计系统。

## 布局

- 桌面沿用品牌介绍 + 表单双栏结构；账号动作始终在右侧同一张表单卡中完成。
- 移动端隐藏大幅品牌介绍，只保留紧凑 Wordmark 和表单。
- 表单宽度不超过 404px，字段间距 20px，避免安全表单过密。

## 表单

- 每个字段使用可见 label、正确的 `type` 和 `autocomplete`。
- 密码字段提供显示/隐藏按钮，按钮命中区域至少 44px。
- 登录使用 `current-password`；注册和重置使用 `new-password`。
- 错误紧邻表单并使用 `role="alert"`；成功结果使用 `role="status"`。
- 忘记密码无论邮箱是否存在都展示相同成功文案，避免账号枚举。

## 一次性链接

- `verifyToken` 进入邮箱验证状态；`resetToken` 进入重置密码状态。
- 验证中显示明确进度；成功、失效和已使用状态都有下一步入口。
- Token 不写入本地存储，完成后从地址栏移除。

## 主要动作

- 每个状态只有一个 Primary，例如“登录”“发送重置邮件”“设置新密码”。
- 返回登录、创建账户属于 Text/Secondary 操作。
- 提交期间禁用按钮并保持尺寸稳定。
