# 知识库与引用规范

本文件定义知识库管理和回答引用的页面级规则。未列出的内容继承 `../MASTER.md`、`../COMPONENTS.md` 和 `chat.md`。

## 页面目标

让用户知道三件事：资料是否处理完成、这次提问查了哪些知识库、回答依据来自哪一段原文。界面不出现向量、Embedding 或 Top-K 等实现术语。

## 知识库

- 侧栏提供“知识库”入口；760px 以下侧栏隐藏时，对话页头提供同等入口。
- 列表与文档区在 1024px 以上并排，760px 以下改为上下排列。
- 创建、重命名使用可见表单。删除使用行内确认，不调用浏览器确认框。
- 文档状态同时使用文字和边框：等待处理、正在读取内容、正在整理段落、正在准备检索、可以引用、处理失败。
- 失败必须展示原因，并提供重试。已可引用的文档提供重新索引。
- 上传中展示文件名和百分比进度。

## 检索范围

- Composer 中知识库选择位于附件之后、模型之前。
- 未选择时明确写“未选择知识库，本次只根据对话回答”。
- 已选择时用芯片列出名称，并说明将在这些资料中查找依据。
- 单次最多选择 8 个知识库，超出后其余选项禁用。

## 引用

- 正文中的 `[n]` 仅在该编号存在于本条回答的引用快照时变成按钮。
- 代码块中的方括号编号保持原文。
- “查看来源”打开引用面板，展示编号、文档名、页码、章节和原文片段。
- 来源文件仍存在时提供下载；文件已删除时保留片段，并说明这是当时保存的内容。
- 面板支持 Escape 关闭，以及方向键、Home、End 切换编号。
- 流式生成尚未返回引用时展示加载状态；完成后没有引用时展示空状态；下载失败展示错误状态。
